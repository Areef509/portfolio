## ✦ Overview

A modern, highly interactive personal portfolio website built for **Mohammed Areef A** (B.E. Artificial Intelligence & Machine Learning, Chennai, India). 

Designed with an **editorial, art-directed philosophy** inspired by award-winning creative developer portfolios:
- **Oversized Display Typography** with tight leading and Swiss-style precision.
- **Asymmetric Layouts & Whitespace** prioritizing storytelling over generic card grids.
- **Spring-Physics Custom Cursor** with contextual project hover actions (`VIEW CASE STUDY →`).
- **Interactive Architectural Case Study Drawers** detailing end-to-end ML workflows, system topology, latency benchmarks, and evaluation metrics.
- **Lenis Smooth Inertia Scrolling** and synthesized Web Audio micro-haptics.
- **Seamless Dual-Theme (Dark / Light)** support defaulting to a near-black charcoal aesthetic.

## ✦ Getting Started

```bash
# Clone the repository
git clone https://github.com/Areef509/portfolio.git

# Navigate to project directory
cd portfolio

# Install dependencies
npm install

# Start local development server
npm run dev

# Build for production
npm run build
```
